# 功能與操作指南

## 準備網頁檔案

在 Chrome 開啟要展示的頁面。若圖片要滑到附近才會載入，先瀏覽相關區段，再用「另存網頁」選 **網頁，完整**。通常會得到一份 HTML 和旁邊的素材資料夾。維持兩者名稱及相對位置。

| 匯入方式 | 選擇內容 |
| --- | --- |
| **ZIP** | 將入口 HTML 和素材資料夾一起壓縮，再選取 ZIP。 |
| **HTML** | 選擇入口 HTML，並在同一面板選取 Chrome 建立的素材資料夾。獨立的單檔 HTML 可以直接解析。 |
| **完整資料夾** | 選取同時包含入口 HTML 與素材的上層資料夾。 |

如果有缺圖，可在同一頁另外用 **單一檔案**格式儲存，將產生的 `.mhtml` 或 `.mht` 加到「缺圖時加入 Chrome 封存」。工具會嘗試用其中對應網址的圖補回缺圖。支援的入口檔仍需透過上表其中一種方式提供。

「自動下載缺少的 HTTPS 圖片與字型」會在匯入時嘗試取得公開資源。若要全程離線，請取消勾選。匯入上限為 80 MB；ZIP 解壓後上限也是 80 MB，且最多 2,500 個檔案。

## 解析與檢查

1. 選好檔案後按 **解析網頁**。按鈕下方會顯示進度與目前階段。只在有相關工作時顯示補齊素材或驗證版面調整的階段。
2. 成功後會進入預覽。展開 **查看各寬度與缺少的素材**，可查閱 1440、1024、834、768、600、390 和 320 px 的水平溢出量，以及素材下載結果。
3. 工具會嘗試調整可辨識的超寬容器、媒體或卡片群組。仍有溢出時可選相近尺寸定位。RWD 檢查的數值著重於水平溢出，視覺和互動仍應在預覽中確認。
4. 解析失敗時會顯示錯誤並保留這次選的檔案，可更換檔案後再試。點 **重新匯入**會從空白表單開始。

## 展示與調整

可在預覽切換 **手機｜平板｜桌機**，或用欄位、滑桿調整寬度。桌機模式可按 **自動寬度**填滿預覽區。

| 功能 | 操作 |
| --- | --- |
| **Logo 替換** | 可一次替換所有辨識到的 Logo，或展開個別設定。可調整寬高、比例鎖定、顯示狀態與位置。尺寸和位置可依裝置調整。 |
| **導覽項目** | 辨識到可編輯的導覽後，可修改、增減項目，按 **套用導覽**；也可單獨重置導覽。 |
| **輪播設定** | 保留可辨識的輪播操作與版型。出現設定時，可換圖或調整轉場及速度曲線。無法辨識完整結構時，保留封存中的可見畫面並提示。 |
| **重置** | 右上角的重置會讓目前頁面回到剛完成解析時的設定。 |

## 下載與離線驗收

右上角按 **下載**，瀏覽器會儲存 ZIP。請完整解壓縮，在解壓資料夾裡開啟入口 HTML。資料夾內的素材需要和 HTML 保持相對位置。調整結果會寫入匯出內容，離線開啟時可以查看。

建議下載後關閉網路，再從頁首滑到頁尾。檢查窄版導覽、圖片、頁內連結、輪播切換及需要示範的區段。本機服務重新啟動後，請重新匯入原始檔案。已下載的 ZIP 可獨立開啟。

## 支援範圍與排解

| 狀況 | 處理方式 |
| --- | --- |
| 匯入後像純文字 | 確認 HTML 和 Chrome 產生的樣式、素材資料夾一起匯入，且原本的檔名及路徑未變。 |
| 部分圖片或字型沒有顯示 | 展開 RWD 檢查結果查看缺少的素材。重新用「網頁，完整」儲存，或加入同一頁的 Chrome 封存補圖。遠端資源能否取得取決於原站和網路。 |
| 影片或外部服務不能操作 | 靜態匯出會停用原站 scripts、表單送出、跨頁連結與嵌入 iframe。登入、購物車、外站影片、即時資料等需由原站或另外的整合提供。 |
| 輪播或其他頁內按鈕無法操作 | 工具為已辨識的結構重建頁內互動。其他元件可能只保留當時的畫面。 |
| Chromium 找不到 | 依 README 執行 `npm run install-browser`。也可設定 `CHROME_PATH` 指向相容的 Chrome 或 Chromium 執行檔。 |
| 本機埠被占用 | 設定環境變數 `PORT` 後再執行 `npm start`，開啟終端機顯示的本機網址。預設埠為 8882。 |
